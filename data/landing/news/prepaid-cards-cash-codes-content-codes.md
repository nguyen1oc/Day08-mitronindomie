# Prepaid Cards, Cash Codes, & Content Codes

Redeeming codes for premium currency or in-game content is a great way to fill out your account. While you can use any of those codes at our one-stop Code Redemption page, there are a few things you may want to know—including how to redeem those codes for different games.

---

## Cash Codes (Prepaid/Gift Cards)
Cash codes is a catch-all term that includes Prepaid Cards and Gift Cards (like Riot PIN).

- **What they get you:** Premium currency for Riot's games (RP, VP, etc.).
- **Where to buy them:** Physical stores or online retailers. Look for a scratch-off code on physical cards or a text code sent via email for digital ones.

### Important Rules for Cash Codes
1. **One Code, One Game, One Use:** You must use the whole code on one game only, and the full amount will be added to your account instantly. You can't split it between games or accounts!
2. **Region Locked:** You can only redeem cash codes in the region where they were purchased.
3. **PC Only:** Cash codes can only be redeemed in the PC versions of our games. If you're playing on console, use our Code Redemption page.
4. **No Expiration:** Cash codes never expire!

> **Keep Your Card and Receipt!**  
> If anything goes wrong during redemption, Player Support will need both to help you fix it.

---

## Content Codes
- **What they get you:** A specific piece of in-game content—maybe a cool League of Legends ward, a VALORANT gun buddy, an icon, or a skin.
- **Where to get them:** They're usually given out by streamers, distributed at events, or included as part of a promotion.

### Important Rules for Content Codes
1. **Single-Use:** Once used, the code is done. Make sure you're logged into the right account!
2. **No Duplicates:** If your account already owns the content the code grants, you won't get it again, and you won't get a refund, shards, or essence. The code will still be considered "used."
3. **Region Free:** Generally, content codes work across regions (with very few exceptions).

---

## How to Redeem Cash Codes
1. Go to `https://shop.riotgames.com/redeem`.
2. Enter your code exactly as it appears on the card, email, or receipt, then select the **Redeem Code** button.  
   *(Note: If you are not already logged in, you will be prompted to log in to the account where you wish to add the virtual currency/content after entering your code).*
3. Select the game you wish to use the cash code in. Codes can only be redeemed in one game and cannot be partially redeemed. If a game title is gray, it means this account has not yet played this game.
4. Confirm the information on the summary page that appears after, including your current balance and the amount of premium currency added with this cash code. If everything looks right, select **Redeem Code**. Select **Cancel** if you'd like to redeem it for a different game.
5. **Success!** The premium currency should be added to your account instantly (in some cases it may take up to 24 hours).

---

## How to Redeem Content Codes
1. Go to `https://shop.riotgames.com/redeem`.
2. Enter your code exactly as it appears on the card, email, or receipt, then select the **Redeem Code** button.  
   *(Note: If you are not already logged in, you will be prompted to log in).*
3. A page will display the content to be added, along with a request for confirmation. Check that you do not already have this content.
4. Once you're satisfied that the content isn't already in your account, select **Redeem Code**.
5. **Success!** Content is added instantly or within 24 hours.

## Game-Specific Redemption Guide

### Redeeming Your Code in VALORANT
1. Log in to the VALORANT game client and click on the VALORANT icon located by your VP in the upper right corner.
2. Select **Prepaid Cards & Codes** and input your code exactly as it appears.
3. In some regions, tick the consent box before clicking **Submit**.

### Redeeming Your Code in League of Legends and Teamfight Tactics
1. Go to the Store and click the **Account** button.
2. Select the **Redeem Codes** option.
3. Enter the code exactly as it appears and press **Submit**.

### Redeeming Your Code in Legends of Runeterra
1. Log in to the LoR client, navigate to the Store, and click on the `+` icon.
2. Select the **Prepaid Cards & Codes** payment method.
3. Enter the code exactly as it appears (accept the consent box if prompted) and press **SUBMIT**.

### Redeeming Your Card in 2XKO
1. Log in to your account in the client and select the **P** located on the top right next to the currency balance.
2. Select **Prepaid Cards and Codes**.
3. Enter the code exactly as it appears (tick the consent box if required) and click **Submit**.

## Common Errors & How to Fix Them

| Error Message | What It Means | Quick Fix |
| :--- | :--- | :--- |
| `"This Code Does Not Appear to Be Valid or not found"` | The code you entered doesn't exist in our system. | Double-check that you typed the code correctly. **DO NOT include any spaces** (e.g., use `123456789` not `123 456 789`). |
| `"This Code Appears to Not Be Properly Activated"` | The store you bought the card from didn't properly activate it at the register. | Go back to the merchant/store and ask them to properly activate your card. |
| `"This Code Has Already Been Redeemed"` | The code has been used on an account. | Check if you've already redeemed it. If gifted or bought from a 3rd party, contact the seller or Player Support. |
| `"You Have Exceeded the Maximum Number of Code Redemption Attempts"` | You've tried too many codes recently. | Wait 24 hours before trying to redeem any more cards. |
| `"This Code is Not Valid in Your Region"` | Your cash code is locked to a specific region/currency and cannot be used on your current account's server. | Cash codes are region-specific. You must use it on the server it was issued for. |

## Other Issues & Policy Details

### Over-Scratching
If you've over-scratched your card or are getting a persistent error:
1. Go to the **Player Support Page** and click **Submit a ticket**.
2. Include the following info:
   - The code itself and the store receipt.
   - Your **Riot ID**.
   - The email used for your Riot Account.

### Third-Party Retailers
We highly advise you **NOT** to purchase prepaid cards from third-party sites like online auctions or non-authorized retailers. We cannot guarantee their legitimacy or validity.

### Support Limits
Player Support cannot help with codes that have already been redeemed on a different account, expired content codes, or used cash codes.
